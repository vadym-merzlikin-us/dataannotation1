# codejunk-frontend

Angular 20 SPA for the CodeJunk annotation queue. See the
[root README](../README.md) for the full stack and the Docker Compose setup.

```bash
npm install
npm start        # http://localhost:4200, proxies /api to localhost:8080
npm run build    # production bundle in dist/codejunk-frontend/browser
npm test         # Karma + Jasmine (needs Chrome)
```
